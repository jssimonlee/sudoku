# 프리미엄 수도쿠 웹 게임

순수 HTML, CSS, JavaScript로 만든 모던 반응형 수도쿠 게임입니다.  
글래스모피즘 UI, 다양한 편의 기능을 지원합니다.

## 주요 기능 ✨

- **프리미엄 UI** – 라이트 테마, 글래스모피즘 효과, 부드러운 애니메이션
- **스마트 퍼즐 생성** – 논리만으로 풀 수 있는 퍼즐만 출제 (찍기 최소화), 유일 정답 보장
- **4단계 난이도** – 쉬움 / 보통 / 어려움 / Expert
- **실시간 검증** – 오류 즉시 감지, 흔들림 애니메이션 & 실수 카운트 (3회 초과 시 게임 오버)
- **하이라이트** – 선택 셀의 행·열·박스·같은 숫자 자동 강조
- **숫자 완성 연출** – 숫자 9개 완성 시 에메랄드 그린 캐스케이드 파도 & 팡파레 효과
- **게임 클리어 연출** – 1~9번 순서 전체 보드 캐스케이드 후 결과 팝업
- **메모 모드 (Notes ✏️)** – 빈 칸에 예상 숫자 1~9 기입, 재클릭 시 삭제, 정답 확정 시 관련 셀 자동 제거 (Undo로 함께 복원)
- **번호 선택 & 빠른 입력** – 번호 하나를 선택해두고 빈 칸 더블클릭 또는 **F / ` / ~ / Space / Esc 키**로 빠르게 입력
- **일시정지 (Pause ⏸)** – 보드를 가리고 타이머 정지, 중앙 ▶ 또는 **일시정지 상태에서만 Space 키**로 재개 (일시정지 중에는 입력 불가)
- **TOP 10 순위표 (🏆)** – 모드별 상위 10개 기록을 서버에 저장, 순위에 들 때만 이니셜 입력 후 전송
- **자동 저장** – 진행 중인 게임(보드, 메모, 시간, 실수, 콤보 점수)을 브라우저에 저장해 새로고침해도 이어서 플레이
- **실행 취소 (Undo)** – 이전 입력으로 되돌리기
- **반응형** – 모바일·데스크톱 모두 최적화
- **화려한 게임 효과 ✨** – 정답 반짝임·음계 효과음, 줄/박스 완성 물결, 숫자 완성, 클리어 컨페티 (ON/OFF, 끄면 기본 효과만)
- **콤보 모드 🎲** – 정답을 넣는 *순서*로 족보를 만들어 점수 획득 (스도쿠 규칙은 그대로)
- **오늘의 퍼즐 📅** – 날짜로 만든 퍼즐을 모두가 똑같이 풀고, 그날만의 순위표에서 겨루기 (연속 출석 표시)
- **개인 기록 🏅** – 클리어할 때마다 난이도별 최고 시간·최고 콤보 점수·클리어 횟수를 결과 창에 표시

## 조작 방법 🎮

`index.html`을 브라우저에서 바로 열어 플레이 (별도 설치 불필요)

| 동작 | 방법 |
|---|---|
| 숫자 입력 | 셀 클릭 → 화면 숫자 패드 또는 키보드 1~9 |
| 번호 선택 | 숫자 패드 클릭 / 키보드 1~9 / 보드 안 숫자 클릭 |
| 선택 번호 빠른 입력 | 빈 칸 더블클릭 또는 **F / ` / ~ / Space / Esc 키** |
| 메모 입력 | Notes ✏️ 활성화 후 숫자 클릭 (토글) |
| 지우기 | Erase 버튼 또는 Backspace / Delete |
| 실행 취소 | Undo 버튼 또는 Ctrl+Z / Cmd+Z |
| 방향 이동 | 방향키 ↑↓←→ |
| 일시정지 / 재개 | ⏸ 버튼, 또는 일시정지 상태에서만 Space |
| 콤보 모드 ON/OFF | 🎲 버튼 (헤더 우상단) |
| 효과 설정 | ✨ 버튼 (헤더 우상단) – 화려한 효과·콤보 효과·소리·진동 |

## 게임 규칙

- 각 행, 열, 3×3 박스에 1~9가 하나씩만 들어가야 합니다.
- 오류 3회 발생 시 게임 오버.

## 화려한 게임 효과 ✨

헤더의 ✨ 버튼으로 여는 **효과 설정**에서 켜고 끌 수 있습니다 (기본 ON, 브라우저에 저장). 끄면 기존 기본 효과만 동작합니다.

| 상황 | 효과 |
|---|---|
| 정답 입력 | 숫자가 도장처럼 칸에 찍히며 파랗게 반짝, 작은 파티클, 짧은 진동, 숫자마다 다른 음 (1=도 … 9=레, 순서대로 넣으면 음계) |
| 숫자 패드 | 누른 번호 버튼이 눌렸다 튕김. 그 숫자가 하나만 남으면 버튼이 초록빛으로 은은하게 빛남. 이미 다 채운 번호를 누르면 보드의 그 숫자 9칸이 초록색으로 물결치듯 깜빡임 |
| 줄·열·박스 완성 | 완성한 칸에서 퍼져 나가는 물결과 함께 숫자들이 차례로 튀어 오르고, 줄은 빛줄기·박스는 터지는 사각형으로 구분. 두 줄 이상 동시에 완성하면 "더블 라인!"과 보드 흔들림, 세 줄이면 "트리플 라인!"과 큰 파티클 |
| 숫자 9개 완성 | 기존 연출에 더해 "7 완성!" 표시, 파티클, 아르페지오 |
| 퍼즐 클리어 | 전체 화면 배너, 컨페티, 보드 테두리 빛, 팡파레 |
| 실수 (생명력 감소) | 빠진 생명력 칸이 깨지며 붉은 파편, 화면 가장자리 붉은 플래시, 보드 흔들림, `-1`. 생명력이 줄수록 강해지고, 마지막 1칸이면 "마지막 기회!" 배너와 남은 칸이 붉게 깜빡임 |

## 콤보 모드 🎲

정답을 넣는 **순서**대로 최대 5장의 패를 만들고, 패가 끝날 때 점수를 받습니다. 패널의 **족보** 버튼을 누르면 예시와 함께 족보표를 볼 수 있습니다.

| 족보 | 예시 | 점수 |
|---|---|---|
| 파이브 카드 | 7 7 7 7 7 | 250 |
| 스트레이트 5 | 4 5 6 7 8 (9 8 7 6 5도 가능) | 200 |
| 풀하우스 | 2 2 5 5 5 / 5 5 5 2 2 | 150 |
| 포카드 | 1 1 1 1 | 120 |
| 스트레이트 4 | 3 4 5 6 | 80 |
| 투 페어 | 3 3 6 6 | 50 |
| 트리플 | 7 7 7 | 40 |
| 스트레이트 3 | 1 2 3 | 30 |
| 페어 | 4 4 | 10 |
| 2연속 | 5 6 | 10 |

- 최고 족보나 5장이 되면, 또는 더 이을 수 없으면 바로 확정되고 새 패가 시작됩니다.
- 흐름이 끊기는 번호를 넣으면 지금까지의 패를 확정하고, 그 번호로 새 패를 시작합니다.
- 실수하면 확정 전 패는 날아갑니다. 퍼즐을 완성하면 남은 패도 확정됩니다.
- 숫자 패드의 `+점수`와 **다음 예상** 목록은 패를 더 높여주는 번호만 보여줍니다 (칸 위치는 알려주지 않음).
- 방금 넣은 칸을 Undo/지우기 하면 그 입력 전 상태로 돌아갑니다. 이전 칸을 지우고 다시 넣으면 점수가 없습니다.
- 자동 채우기(F 등)도 일반 입력과 똑같이 계산됩니다.

### 게임 효과

족보가 높을수록 효과가 강해집니다. 소리는 음원 파일 없이 브라우저에서 합성합니다.

| 단계 | 족보 | 효과 |
|---|---|---|
| 1 | 페어, 2연속 | 칸 반짝임, `+점수` 떠오름, 짧은 효과음 |
| 2 | 스트레이트 3, 트리플, 투 페어 | 칸이 입력 순서대로 빛남, 점수 카운트업, 차임, 작은 파티클 |
| 3 | 스트레이트 4, 포카드 | 보드 위 배너, 파티클 폭발, 아르페지오, 보드 흔들림, 진동 |
| 4 | 풀하우스, 스트레이트 5, 파이브 카드 | 전체 화면 배너, 컨페티, 보드 테두리 빛, 팡파레, 강한 흔들림, 진동 패턴 |

- **실수**: 슬롯의 칩이 떨어지고 낮은 효과음이 납니다.
- **열기 🔥**: 실수 없이 연속 확정하면 숫자가 오르고 패널 테두리가 달아오릅니다. 5연속부터 효과가 한 단계 강해집니다 (점수에는 영향 없음).
- **설정**: 헤더의 ✨ 버튼(또는 족보 팝업의 **효과·소리 설정**)에서 콤보 효과, 소리, 진동을 켜고 끌 수 있고, 패널의 🔊 버튼으로 소리를 바로 끌 수 있습니다. 설정은 브라우저에 저장됩니다.
- OS의 "동작 줄이기"가 켜져 있으면 흔들림과 컨페티를 생략합니다.

## 오늘의 퍼즐 📅

난이도 목록에서 **📅 Daily**를 고르면 시작합니다.

- 퍼즐은 날짜를 시드로 만들어 **모든 기기에서 같은 판**이 나옵니다 (Medium 크기, 한국 시간 자정에 바뀜).
- 순위는 **그날 첫 클리어 기록**만 겨룹니다. 중간에 다시 시작해도 **쓴 시간은 이어집니다** (다시 시작으로 시간을 줄일 수 없음).
- 클리어한 뒤 다시 풀면 연습이라 기록·순위에 남지 않습니다.
- 매일 이어서 클리어하면 **연속 출석** 일수가 올라갑니다. 하루를 거르면 1일부터 다시 셉니다.
- 오늘의 퍼즐은 시간으로만 겨룹니다. 콤보 모드를 켜고 풀어도 점수는 순위에 들어가지 않습니다.

## 개인 기록 🏅

클리어하면 결과 창에 이번 판의 시간·실수와 함께 다음을 보여줍니다.

- 모드·난이도별 **최고 시간**과 **최고 콤보 점수** (갱신하면 `개인 최고!` 표시)
- 콤보 모드에서 이번 판에 확정한 **최고 족보**
- 그 모드·난이도의 **클리어 횟수**

기록은 이 브라우저에만 저장됩니다 (서버로 보내지 않음).

## TOP 10 순위표 🏆

모드별로 상위 10개 기록만 서버(Cloudflare Worker + D1)에 저장합니다. 로그인은 없습니다.

| 순위표 | 기준 | 동점 |
|---|---|---|
| 일반 Easy / Medium / Hard / Expert | 시간이 짧은 순 | 실수 적은 순 → 먼저 등록한 기록 |
| 콤보 시간 × 4 | 시간이 짧은 순 | 실수 적은 순 → 먼저 등록한 기록 |
| 콤보 점수 × 4 | 점수가 높은 순 | 시간이 짧은 순 → 먼저 등록한 기록 |
| 오늘의 퍼즐 (날짜별) | 시간이 짧은 순 | 실수 적은 순 → 먼저 등록한 기록 |

- 클리어하면 **저장해 둔 순위표(캐시)** 와 먼저 비교합니다. 순위표는 좋아지기만 하므로, 캐시의 10등보다 못하면 실제로도 들 수 없어 **서버에 요청하지 않습니다.**
- 캐시 기준으로 10등 안에 들면 이니셜(영문·숫자 3글자)을 입력해 등록합니다. 서버가 실제 순위로 다시 판정하고 최신 순위표를 돌려줘 캐시를 바꿉니다.
- 콤보 모드는 한 판으로 시간·점수 두 순위표를 함께 판정합니다 (이니셜은 한 번만).
- 헤더의 🏆 버튼으로 순위표를 볼 수 있습니다 (서버 주소가 설정됐을 때만 보임).

### 보안

- 모든 쿼리는 바인딩(`prepare().bind()`)으로 실행해 SQL 인젝션을 막습니다.
- 이니셜은 서버에서 `A-Z 0-9` 3글자만 허용하고, 화면에는 `textContent`로만 출력합니다.
- 서버 검증: 난이도별 최소 시간, 콤보 점수 최대치, 실수 0~2회, 금지 이니셜, 요청 크기.
- 같은 IP(해시로만 저장)는 10분에 5번까지만 등록할 수 있습니다.
- CORS로 허용한 주소에서만 브라우저 등록이 됩니다 (스크립트 직접 호출은 위 검증으로 막음).
- 선택: Cloudflare Turnstile 봇 확인.
- 삭제·초기화 API는 없습니다. 관리는 `wrangler d1 execute`로 직접 합니다.

### 서버 설정 (wrangler)

`worker/` 폴더에 Worker 코드(`src/index.js`), 설정(`wrangler.toml`), 테이블(`schema.sql`)이 있습니다.
D1 `mydb`를 다른 프로젝트와 함께 쓰므로 테이블과 인덱스는 모두 `sudoku_` 접두어를 씁니다.

```bash
# 1. 로그인 (처음 한 번, 브라우저가 열림). 이미 로그인돼 있으면 생략
wrangler login
wrangler whoami

# 2. 테이블 만들기 (worker 폴더에서)
cd worker
wrangler d1 execute mydb --remote --file=schema.sql

# 3. (선택) 비밀 값
wrangler secret put RATE_LIMIT_SALT       # 아무 긴 무작위 문자열
wrangler secret put TURNSTILE_SECRET      # Turnstile을 쓸 때만

# 4. 배포 → https://sudoku-api.<계정>.workers.dev 주소가 출력됨
wrangler deploy
```

5. 출력된 주소를 `leaderboard-config.js`의 `apiBase`에 넣고 커밋·푸시하면 순위표가 켜집니다.
   Turnstile을 쓰면 `turnstileSiteKey`도 넣습니다.

로컬 테스트:

```bash
cd worker
wrangler d1 execute mydb --local --file=schema.sql
wrangler dev --local --port 8787
```

`leaderboard-config.js`의 `apiBase`를 `http://127.0.0.1:8787`로 잠시 바꾸고, 게임은 `python -m http.server 8765`로 엽니다.

관리 예시:

```bash
wrangler d1 execute mydb --remote --command "SELECT * FROM sudoku_scores ORDER BY board"
wrangler d1 execute mydb --remote --command "DELETE FROM sudoku_scores WHERE id = 123"
```
